# 💻 Namrata Pise — Portfolio Website

An interactive, responsive, and modern personal portfolio website built to showcase engineering projects, AI/ML models, data visualization dashboards, and professional certifications. 

👉 **Live Demo:** [namrata-pise.vercel.app](https://namrata-pise.vercel.app/)

---

## ✨ Features

- **Dynamic Hero Section:** Engaging introduction highlighting current role as an **AIML Engineer & Data Analyst**, with quick access to resume download and projects.
- **Interactive Navigation & Theme:** Responsive header with smooth scrolling across sections and a light/dark mode theme toggle.
- **Education Timeline:** Highlights academic background, including B.Tech in CSE (Artificial Intelligence and Machine Learning) at PR Pote College of Engineering and Management, Amravati.
- **Internships & Certifications:** Comprehensive track record of virtual internships and professional credentials (EduSkills/AICTE, Simplilearn, Forage Cybersecurity).
- **Featured Projects Showcase:** Interactive cards detailing top technical works, including:
  - **Smart Meter Installation Progress Dashboard** (Power BI & SQL)
  - **E-Commerce UI Kit** (HTML/CSS, JS, Stripe API)
  - **Smart Feedback Portal** (JS, Sentiment Analysis, API)
- **Skills Breakdown:** Animated proficiency meters covering Data Analysis, Web Development, Deep Learning, Databases, Data Visualization, and Agentic AI.
- **Toolbox Grid:** Visual showcase of daily tools and platforms used (VS Code, MySQL, Power BI, MongoDB, AWS, Postman, etc.).
- **Contact & Social Hub:** Direct contact channels (Email, Phone, Location) and links to GitHub, LinkedIn, and Instagram.

---

## 🛠️ Tech Stack

- **Markup & Styling:** HTML5, CSS3, Modern JavaScript (ES6+)
- **Hosting & Deployment:** Vercel
- **Icons & Visuals:** Unsplash, Custom CSS Animations
